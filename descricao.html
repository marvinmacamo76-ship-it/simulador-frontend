Descrição e Arquitetura do Projeto

Simulador Interativo de Geometria Molecular e Polaridade — Universidade Licungo · Abordagem STEM

🎯 O que é e para que serve?

O STEM Licungo é uma plataforma educacional web interativa desenvolvida para apoiar o ensino e a aprendizagem de Química. O seu principal objetivo é transformar conceitos abstratos de Geometria Molecular — baseados na Teoria de Repulsão dos Pares de Eletrões da Valência (TREPV/VSEPR) — em experiências visuais tridimensionais, dinâmicas e acessíveis para estudantes e professores.

Missão Educacional: Eliminar a barreira do laboratório físico, permitindo que qualquer estudante visualize estruturas químicas em 3D em tempo real diretamente no navegador, sem instalações, sem custos adicionais e com dados reais do PubChem.

🇲🇿 Contexto Académico e Abordagem STEM

Desenvolvido no âmbito das iniciativas académicas da Universidade Licungo em Moçambique, o projeto aplica a metodologia STEM (Ciência, Tecnologia, Engenharia e Matemática), integrando o raciocínio científico da Química com o desenvolvimento de software moderno. A ferramenta foi concebida para responder às reais necessidades pedagógicas do contexto moçambicano, promovendo a literacia digital e científica nas salas de aula do ensino superior e secundário.

✨ Funcionalidades Atuais

🔬 Visualizador de Geometria Molecular 3D

  • Renderização WebGL em tempo real com 3Dmol.js a partir de dados SDF 3D do PubChem
  • Dois modos de visualização: Bastões e Esferas (ball-and-stick) e Só Esferas CPK (espaço preenchido)
  • Rotação automática a 1.5× de velocidade; pausa ao interagir e retoma ao soltar
  • Inferência automática da geometria VSEPR (linear, angular, tetraédrica, piramidal trigonal, etc.)

📐 Sobreposições Científicas

  • Símbolos dos elementos — etiquetas com o símbolo e cor CPK de cada átomo
  • Ângulos de ligação — arco curvo fino entre os pares de ligações com o valor em graus ao lado
  • Pares de eletrões livres — esferas translúcidas cinzentas com dois pontos amarelos (estilo VSEPR/PhET), posicionadas por minimização de energia de Coulomb
  • Vetor dipolo molecular (μ) — seta laranja com magnitude em Debye; mostra "Apolar" quando μ ≈ 0

📚 Biblioteca de Moléculas

  • Mais de 40 moléculas organizadas em 5 categorias: Orgânicas, Inorgânicas, Iónicas, Elementares e Complexas
  • Pesquisa em tempo real por nome ou fórmula
  • Acesso direto ao visualizador 3D de cada molécula

📖 Literatura Científica

  • Descrição química do composto obtida automaticamente do PubChem
  • Até 3 artigos científicos relacionados via CrossRef (gratuito, sem limites de taxa)
  • Tradução automática de todo o conteúdo para Português via API MyMemory — sem necessidade de chave de API

⚙️ Arquitetura de Software e Tecnologias

Camada Tecnologia Função
Backend Node.js 20 Express Servidor HTTP, proxy das APIs externas (CORS), servir ficheiros estáticos
Visualização 3D 3Dmol.js Renderização WebGL de moléculas a partir de SDF; átomos, ligações, setas, esferas e etiquetas
Dados moleculares PubChem REST API Estruturas SDF 3D/2D, propriedades químicas (fórmula, massa molar, carga…) e descrições
Literatura CrossRef API Busca de artigos científicos por nome IUPAC da molécula; gratuito e sem chave
Tradução MyMemory API Tradução automática de descrições e resumos de artigos para Português no servidor
VSEPR / Matemática JavaScript puro Inferência de geometria, cálculo de ângulos, slerp para arcos, minimização de Coulomb para pares livres
Frontend HTML5 CSS3 ES6+ Interface responsiva sem frameworks; funciona em computadores, tablets e telemóveis
